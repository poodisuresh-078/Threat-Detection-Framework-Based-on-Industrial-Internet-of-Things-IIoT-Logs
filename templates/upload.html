Required CSV Schema

Specification

The ingested CSV file must contain the following 7 columns (case-insensitive):

timestamp String / DateTime
Standard ISO/UTC or YYYY-MM-DD HH:MM:SS format.
device_id String
Unique identifier for industrial controller (e.g. PLC-01, SCADA-RTU-04).
source_ip IPv4 String
Originating IP address transmitting packets or commands.
event_type String
Industrial event description (e.g. telemetry_read, brute_force_login, port_scan).
failed_logins Integer
Consecutive failed authentication attempts registered (>= 0).
network_traffic Float / KB
Total transmitted network payload in Kilobytes (KB).
status String
Operation outcome status (success, normal, failed, timeout, rejected, error).
